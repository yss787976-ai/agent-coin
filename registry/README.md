# Discovery hosting

Agents look in fixed places. Publish all four, in this order:

1. `/.well-known/agent-coin.json` — copy `publish/.well-known/agent-coin.json` (generated by `node scripts/gen-discovery.mjs`).
2. `/.well-known/agent-card.json` — your card, then take its hash and `updateCard(hash)` in the registry.
3. DNS TXT `_aqb.<host>` = `v=aqb1;token=0x…;chain=…`.
4. `/llms.txt` entry.

Verify from a shell:
```
curl -s https://<host>/.well-known/agent-coin.json | jq .aqb
dig +short TXT _aqb.<host>
```

If any of the four is missing, compliant clients will not route to you.
