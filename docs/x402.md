# x402-style flow (agent payments)

AQB is the payment leg of a 402 handshake. No accounts, no API keys for the money path.

Live example: `https://agentqubit.pages.dev/a2a/card` (Worker origin: `https://aqb-x402.aqb-foundation.workers.dev`)

## Client agent

1. `GET https://svc.example/a2a/task` → `402` with:
   - `x-aqb-token`
   - `x-aqb-chain`
   - `x-aqb-price`
   - `x-aqb-payto`
   - `x-aqb-accept`
2. Read `x-aqb-payto`; assert `AgentRegistry.isAgent(payTo)` is true, else abort.
3. Pay: `token.transfer(payTo, price)` (or stealth if you want the payer hidden).
4. Retry with `X-AQB-Tx: <hash>`.
5. The service verifies the receipt: `Transfer(from=payer, to=payTo, value>=price)` in that tx, receipt status `0x1`.

## Server agent

```js
const receipt = await provider.getTransactionReceipt(req.header("x-aqb-tx"));
if (!receipt || receipt.status !== "0x1") return res.status(402).end();

const paid = receipt.logs.some((log) => {
  if (log.address.toLowerCase() !== TOKEN) return false;
  if (log.topics[0] !== TRANSFER_TOPIC) return false;
  const to = "0x" + log.topics[2].slice(26);
  return to.toLowerCase() === PAYTO && BigInt(log.data) >= PRICE;
});
if (!paid) return res.status(402).end();
```

## Rules

1. Price is in AQB, integer with 18 decimals.
2. Never accept a tx whose `to` is a non-agent.
3. Wait for the receipt; Base's sequencer ordering is the settlement point for this use case.
4. Replay: bind one tx hash to one resource. The live Worker uses a Durable Object and rejects a second use with `402 payment already used`.
5. The Worker holds no private keys; it only reads Base RPC and verifies receipts.

## Stealth variant

The payer derives `stealthFor(recipientKemKey)`, pays that address, and announces it. The server scans announcements with `stealthCheck` and matches `viewTag` first. Payer identity never appears on chain.
