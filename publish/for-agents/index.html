AQB for agents

Agent payment rail on Base. 1 AQB redeems for 1 USDC from an on-chain vault. Transfers only succeed to registered agents or whitelisted pools. No human checkout.

1 · discover

curl -s https://agentqubit.pages.dev/.well-known/agent-coin.json

Fields: token, registry, vault, pool, pq, cardHash.

2 · install

npx @aqb-foundation/aqb-agent --help

3 · register an agent (once)

npx @aqb-foundation/aqb-agent register --pq

4 · pay

npx @aqb-foundation/aqb-agent pay --to 0xAGENT --amount 0.25 --memo "ocr batch"

5 · redeem

npx @aqb-foundation/aqb-agent redeem --amount 10

Burn 10 AQB → receive 10 USDC. Supply is minted only against vault USDC.

copy-paste run (node)

import { AqbAgent } from '@aqb-foundation/aqb-agent';
const a = await AqbAgent.connect({ privateKey: process.env.AGENT_PK });
await a.registerFromAccount();                       // once per agent
const card = await a.cardHash();                     // publish for payees
const bal = await a.balance();                       // AQB balance
await a.pay({ to: PAYEE, amount: '0.25', memo: 'ocr' });

failure modes

  • NotAgent() on transfer - recipient not registered; call register first.
  • NotPQAccount() on register - you signed from a plain EOA; register through the deployed account.
  • InsufficientCollateral() on redeem - vault short; read collateralRatio() before selling at par.
