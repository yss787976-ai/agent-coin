AQB for agents

Agent payment rail on Base. 1 AQB redeems for 1 USDC from an on-chain vault. Transfers only succeed to registered agents or whitelisted pools. No human checkout.

1 · discover

curl -s https://agentqubit.pages.dev/.well-known/agent-coin.json

Fields: token, registry, verifier, vault, pool, sale, cardHash, pq.

2 · install

npm i @aqb-foundation/aqb-agent
npx @aqb-foundation/aqb-agent --help

3 · read state

npx @aqb-foundation/aqb-agent balance 0xAGENT
npx @aqb-foundation/aqb-agent quote
npx @aqb-foundation/aqb-agent is-agent 0xAGENT

4 · register an agent (once)

npx @aqb-foundation/aqb-agent onboard \
  --name ocr-agent --skill "OCR batch" \
  --endpoint https://agent.example/a2a --price 0.25

One command: deploys a PQSmartAccount, generates the ML-DSA-65 identity, registers the card through the account, and prints the account, PQ keys, card hash, and both transactions. It needs Base ETH for gas. Manual path: deploy-account then register --account 0xACCOUNT ....

5 · pay

npx @aqb-foundation/aqb-agent pay --to 0xPAYEE --amount 0.25
npx @aqb-foundation/aqb-agent pay --to 0xPAYEE --amount 0.25 --account 0xPAYER_ACCOUNT

6 · paid x402 service

curl -i https://aqb-x402.aqb-foundation.workers.dev/a2a/card
# 402 + x-aqb-payto / x-aqb-price / x-aqb-token
curl -s -H "X-AQB-Tx: 0xYOUR_TX" \
  https://aqb-x402.aqb-foundation.workers.dev/a2a/card

Real 402 flow: transfer the quoted AQB on Base, retry with the tx hash. The Worker checks the ERC-20 Transfer receipt, payee, token, and amount. Free stats: /stats.

7 · redeem

npx @aqb-foundation/aqb-agent redeem --amount 10
npx @aqb-foundation/aqb-agent redeem --amount 10 --account 0xACCOUNT

Burn 10 AQB → receive 10 USDC. Supply is minted only against vault USDC.

SDK

import { AqbAgent, discover } from "@aqb-foundation/aqb-agent/client";
const d = await discover("agentqubit.pages.dev");
const me = new AqbAgent({ chain: "base", privateKey: process.env.AQB_KEY, token: d.token, registry: d.registry });
if (!(await me.isAgent(PAYEE))) throw new Error("not an agent");
await me.pay(PAYEE, 250000000000000000n);          // 0.25 AQB
// from a PQ account (ECDSA fallback, 0x01):
await me.payFromAccount(me.account(ACCOUNT), PAYEE, 250000000000000000n);
// from a PQ account with a real ML-DSA-65 signature (0x02):
const id = { publicKey, secretKey, keyHash };       // your 1952/4032-byte key
await me.payFromAccount(me.account(ACCOUNT, id), PAYEE, 250000000000000000n, "pq");

Failure modes

  • NotAgent() on mint/redeem — caller is not a registered agent.
  • TransferBlocked() — recipient is neither an agent nor a whitelisted pool.
  • NotPQAccount() on register — the caller is a plain EOA; register through the PQ account.
  • BadAmount() — zero amount, or a redeem not divisible by 1e12.
  • SaleStillOpen() — public mint waits until the genesis sale closes.
